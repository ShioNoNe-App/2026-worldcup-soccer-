# じぶんめくり

四柱推命を入口に、答えるほど自分が見えてくる占い・自己理解 Web アプリ（MVP）。
長い質問票ではなく、**先に命式からの「仮説」を見せ、気になったテーマだけ 1〜3 問ずつ答える**と、回答に応じて次の質問と結果が変わります。

## 実行方法

```bash
cd jibun-mekuri
npm install
npm run dev        # 開発サーバー
npm run build      # 型チェック + 本番ビルド（dist/）
npm test           # ユニットテスト（Vitest）
npm run test:e2e   # E2E テスト（Playwright。ビルドして preview サーバーで実行）
```

バックエンドはありません。`dist/` を任意の静的ホスティングに置けば動きます（`base: './'`）。

## 構成

| ディレクトリ | 役割 |
| --- | --- |
| `src/engine/bazi/` | 四柱推命の計算（命式・五行・通変星・相性の関係）。文章は含まない純粋関数 |
| `src/engine/bazi/sekki-table.ts` | 節入り時刻表（自動生成。`npm run gen:sekki`） |
| `src/engine/diagnosis/` | 仮説の組み立て、適応的な質問選択、結果の組み立て |
| `src/content/` | 解釈文・特性軸・質問・分岐条件・トピック定義（データ） |

| `src/ui/`, `src/screens/` | キャラクター（SVG）、共通部品、各画面 |

### 四柱推命の計算方式

- 入力は日本標準時（JST）。経度による地方時の補正はしない
- 年柱は立春、月柱は十二節の **節入り時刻** で切り替え。月干は五虎遁、時干は五鼠遁
- 日柱はユリウス通日から算出。日の切り替えは 0:00。23 時台は子の刻で、時干は翌日の日干から
- 時刻不明なら時柱なし。節入り日で時刻不明の場合は「未確定」と表示（正午で計算）
- 性別は使わない（性別が必要な「大運」は未実装）
- 節入り時刻は lunar-javascript（MIT）の天文計算から 1899〜2101 年分を生成。
  テストでは同ライブラリを照合用に使い、無作為な 3000 件の日時と、1901〜2099 年の全節入りの ±2 分で一致を確認

### 適応的な質問エンジン

- 命式 → 16 の特性軸に「仮説（prior）」と根拠（basis）を付与
- 回答は特性への効果（effects）と状況タグ（tags）として記録し、毎回、回答履歴から仮説を組み立て直す
- 次の質問は、トピックに関係し、まだ分かっていない特性を優先して選ぶ。`requiresAnyTag` / `excludesTags` で分岐
- 命式からの強い仮説は「心当たりはありますか？」と確認し、「全然ちがう」と答えた仮説は以後押しつけない
- 判明済みの特性の質問は別トピックでも省略。各トピックは最大 2〜3 問（「もう少し深掘り」で追加）
- 結果の各項目に「占いの解釈 / あなたの回答 / 占い×回答」の出典を表示

## 診断のしくみ（3つの占術 × 回答）

- **四柱推命**：命式（年・月・日・時柱）、日干、五行、通変星から仮説を立てる
- **インド占星術（ジョーティシュ）**：astronomy-engine（MIT）で月・太陽の位置を求め、ラヒリのアヤナムシャでサイデリアル黄経に変換。月星座（ラーシ）・27宿（ナクシャトラ）・パダ・太陽星座を算出（`src/engine/jyotish/`）。出生地が必要なアセンダントは未対応
- **16タイプ（任意の自己申告）**：本人が知っているタイプ（MBTI® など）の4指標を仮説に加える。アプリはタイプを判定しない
- 3つの仮説を合成し、回答で具体化・修正する。じぶんマップでは8つの軸のレーダーチャート（仮説＝破線、回答反映＝塗り）、占術どうしの一致・回答とのズレ、回答で開いていく「じぶん取扱説明書」を表示
- テーマごとに「まとめて答える」と、状況に合う質問だけを最後まで続けて出し、終わったらテーマレポートを表示（恋愛は最初に今の状況を聞いて、片思い・交際中・復縁などの質問を出し分け）

## 言語（日本語 / English）

画面右上のボタンで、いつでも全文を英語と日本語に切り替えられます（設定はブラウザに保存）。

- 診断ロジック（ID・効果・分岐）は日本語版のデータを正とし、英語の文章は `src/content/en/` に同じ ID で用意
- トピックの文章は `src/content/topics.ts` に日英併記
- 表示時の切り替えは `src/content/localize.ts`、画面の文言は `useT()`（`T('日本語', 'English')`）
- `src/content/i18n.test.ts` で、英訳の漏れや英語の結果にかなが混ざらないことを検査

## 制約・未実装

- 大運・蔵干の中気／余気・身強身弱・格局などは未実装。五行の集計は天干と地支の本気だけを数える簡易版
- 相性は二人の日柱だけで判断
- 解釈文はこのアプリ独自のもの。占いはエンターテインメントで、結果は事実の断定ではない
- 1948〜1951 年のサマータイムは自動補正しない（説明のみ表示）
- アカウント・クラウド同期・診断履歴の一覧はなし（ブラウザ内保存のみ）
